SECTION 6: DATA MODELS (Simplified, No External Payments)
================================================================================

USER MODEL:
- id: UUID
- email: Email (unique)
- phone: Phone (format: 080xxxxxxxx or +2348xxxxxxxx)
- password_hash: String
- user_type: String (always "dentist" in this version)
- created_at: DateTime
- is_verified: Boolean (default False)

DENTIST PROFILE:
- id: UUID
- user_id: FK → User
- license_number: String (unique)
- full_name: String
- specialty: String (choices: General, Ortho, Prostho, Pediatric, Oral Surgery, Perio, Endo, Cosmetic, Other)
- state: String (Nigerian state)
- lga: String (optional)
- bio: String (max 200 chars)
- consultation_fee: Decimal (in NGN)
- response_time_hours: Integer (default 24)
- average_rating: Float (calculated from consultations)
- total_consultations: Integer (auto-increment)
- created_at: DateTime

CONSULTATION:
- id: UUID
- dentist_id: FK → DentistProfile
- patient_name: String
- patient_phone: String
- patient_email: String
- patient_complaint: String (required)
- status: String (choices: NEW, IN_REVIEW, RESPONDED, RESOLVED)
- dentist_diagnosis: String (null until responded)
- dentist_treatment_plan: String (null until responded)
- dentist_medications: String (null until responded)
- dentist_follow_up: String (null until responded)
- dentist_response_date: DateTime (null until responded)
- rating: Integer (1-5, null until rated)
- rating_comment: String (optional)
- created_at: DateTime
- resolved_at: DateTime (null until resolved)

CONSULTATION_IMAGE:
- id: UUID
- consultation_id: FK → Consultation
- image_file: String (path to local media file)
- uploaded_at: DateTime
- Note: Max 3 images per consultation

SECTION 7: KEY BEHAVIORS & UX PATTERNS
================================================================================

AUTO-SAVE BEHAVIOR:
- When dentist is typing in response form, auto-save every 10 seconds
- Don't save if nothing changed
- Show "Auto-saving..." indicator (small text, bottom-left of form)
- After 2 seconds of no typing, show "Saved" in green
- On page reload/close: Warn user if unsaved changes ("You have unsaved changes")

REAL-TIME STATUS UPDATES (Without WebSockets):
- Dashboard consultations list: Refresh every 30 seconds (silently, via AJAX)
- New consultation arrives: Show a subtle notification (toast/banner at top)
- Toast message: "New consultation from [name]" (green background, #10b981)
- Toast auto-dismisses after 5 seconds

NAVIGATION AFTER ACTIONS:
- After profile setup: Redirect to dashboard
- After submitting response: Redirect to dashboard, show success message
- After rating submission: Show "Thank you for your response" message
- Messages auto-dismiss after 5 seconds

EMPTY STATES:
- "No consultations yet": Centered, with icon + helpful text
- Suggest: "Share your link to get started"
- Button: "COPY YOUR LINK" (primary color)

ERROR MESSAGES:
- Display below field that caused error
- Color: #ef4444 (red)
